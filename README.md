# PukuPop

画像を3D空間に置き、塗った所を平面から持ち上げて、ぷるぷる揺らせる Web アプリです。
ブラウザだけで動き、画像やプロジェクトをサーバーへ送りません。

**すぐに試す: https://ogsoonyn.github.io/PukuPop/**

## 主な機能

### 作る

- **塗って持ち上げる**: ブラシで塗った所が、その場で持ち上がります。筆圧に対応し(強さかサイズに効かせるかは設定で選べます)、レイヤーは8枚まで使えます。揺れはレイヤーごとに付くので、別々に揺らしたい所はレイヤーを分けて塗ります。レイヤー一覧の波のアイコンで、行ごとに揺らす・揺らさないを切り替えられます。
- **範囲を膨らませる**: 楕円や矩形をドラッグして、高さ・断面・角度を決めて一度に膨らませます。描いた範囲は、枠の辺や角で大きさを、中をドラッグして位置を、上の丸で角度を、高さを変えながら直せます。
- **まとめて変える**: 複数のレイヤーを選ぶと、ポップ量や揺れを一度に変えられます。レイヤー一覧の重ね方のアイコンを押すと、その行の重ね方を切り替えられます。

### 揺らす・動かす

- **揺れのプリセット**: 「ぷるぷる」「ばいんばいん」「ためてぼよん」などから選び、硬さ・重さ・減衰も調整できます。
- **手で揺らす**: 画像をつかんで引っ張ったり、画像を動かした勢いや、カメラごと振った動きで揺らしたりできます。
- **操作の記録**: 手で動かした操作を最長60秒覚え、継ぎ目なくループ再生します。
- **キーフレーム**: 視点を最大12個並べて、くり返す動きを作ります。左のツールバーから再生・停止や、経路・ゴーストの表示を切り替えられます。
- **お気に入り**: 揺れと動きの組み合わせを残して、あとで試し比べられます。

### 仕上げる

- **書き出し**: MP4 / WebM / 透過WebM / 連番PNG(ZIP) / GIF。記録した操作やキーフレームの動きは、継ぎ目の揃ったループ動画にできます。
- **保存**: `.pukupop` 形式で保存します。
- **タブ**: 作業を5つまで同時に開き、右上のタブで切り替えます。開いたファイルは新しいタブになり、元に戻す履歴もタブごとに残ります。閉じるのはタブの × か Alt+W、切り替えは Alt+PageDown / Alt+PageUp です。保存していない作業は、開き直したときにタブごと復元できます。スマホでは上の見出しを押すと一覧が出ます。
- **設定**: 右上の歯車から、筆圧の効かせ方や、左のツールバーに出すボタンを選べます(開く・保存・書き出しも出せます。既定では隠しています)。ツールバーの「最近」で、最近開いたファイルをすぐ開き直せます。
- **メモリの使用量**: 下のステータスバーの右端に、開いている作業全部の見積もりを出します。押すと、画像・ウェイト・元に戻す履歴などの内訳が出ます。
- **UIを隠す**: Tab で 3Dビューのほかを隠し、絵を画面いっぱいに見せます。もう一度 Tab か Esc で戻ります。設定で、ブラウザの全画面にもできます。
- **スマホ**: 狭い画面では 3Dビューを全面に出し、設定は下から引き上げるシートにまとめます。塗るツールはシートの「レイヤー」→「塗って直す」にあります。

## 使い方

1. 画像(PNG / JPEG / WebP)をウィンドウへドロップします。
2. ブラシ(B)で動かしたい所を塗ります。
3. 右パネルで揺れのプリセットを選びます。
4. つかむ(G)で画像を引っ張って離すと揺れます。
5. Ctrl+E で動画や画像に書き出し、Ctrl+S で保存します。

### 基本の操作

| 操作 | マウス・キー |
| --- | --- |
| 視点を回す(勢いで揺れる) | 右ドラッグ |
| 視点を傾ける(勢いで揺れる) | Alt+右ドラッグ、← / →(Shift で 1° ずつ) |
| 画像を動かす(勢いで揺れる) | 中ドラッグ |
| ズーム(勢いで揺れる) | ホイール |
| 視点の操作・つかむ・揺らす の精密操作 | Ctrl(⌘)か Shift を押しながら操作 |
| ブラシ / 消しゴム / ぼかし / 膨らみ | B / E / S / I |
| つかむ / 揺らす / 視点 / 移動 | G / Y / V / H |
| 元に戻す / やり直す | Ctrl+Z / Ctrl+Shift+Z |
| ウェイトの重ね表示 / 3面図 / 表示クリア | W / M / C |
| 操作の記録 / ループ再生 / お気に入りに追加 | R / L / K |
| レイヤーを複数選ぶ | Ctrl+クリック、Shift+クリック、Ctrl+A |

スマホでは、1本指で選んだツール、2本指で平行移動とピンチズーム、ひねって傾ける、2本指タップで元に戻す、3本指タップでやり直しです。

## 動作環境

### 動作確認済み環境

- デスクトップ版 Chrome / Edge
- Android Chrome

### 実行環境

| 機能 | 必要なもの |
| --- | --- |
| 表示・編集 | WebGL2 |
| MP4 / WebM の書き出し | WebCodecs |
| 透過WebM の書き出し | アルファ付き VP9 のエンコード(Chromium 系) |
| 上書き保存 | File System Access API(無い場合はダウンロードで保存) |

## ビルド

Node.js 20.19 以降(または 22.12 以降)が必要です。

```sh
npm install
npm run dev       # 開発サーバーを起動する
npm run build     # dist/ へ静的ファイルを出力する
npm run preview   # ビルド結果を確認する
```

## 2026-11-12 複数のレイヤーをまとめて変える・重ね表示を3つにする

- 仕様は単一 HTML の試作で触って決めた。選び方は一覧での複数選択(Ctrl / Shift、スマホは長押し)にした。「選択中 / 全レイヤー」の切り替えだけの案は一部だけを選べず、チェック列の案は表示のチェックとまぎらわしいため。
- ポップ量は「同じ値に揃える」ではなく比率で伸び縮みさせる。膨らみを高さを変えて別のレイヤーに作ったとき、差を保って全体を大きくしたいため。基準は一番高いレイヤーにした(最後に押したレイヤーにすると、それが 0px のときに比率が決まらず、1500px の上限とも合わせにくい)。材質などほかの項目は揃える。
- 変えた項目だけを書く。揺れの設定は `physics` にまとまっているが、1つ変えたときにほかの項目(揺らし方など)を最後に押したレイヤーの値で上書きしないよう、レイヤーごとに作る。
- 全レイヤー表示はレイヤーごとに色を分ける(1色・高さのヒートマップの案より、どこがどのレイヤーかと重なりが同時に見えるため)。選んだレイヤーを濃く、ほかを薄く出す。色は一覧の並びで決め、ファイルには保存しない。先頭は1枚だけ重ねていたころの色。
- 表示のチェックは、選んでいても押した1行だけに効かせる。並べ替えは1枚のときだけ。塗り・膨らみは最後に押したレイヤーだけ。
- 選び方は画面だけの状態で、アンドゥにもファイルにも入れない。重ね表示の「全レイヤー」は `view.overlayAll` として prefs に覚える。
- 一覧のポップ量の横に、重ね方をアイコンで出す(前は「最大 300」の文字)。

## 2026-11-13 ホイールのズームをなめらかにする

- ホイールのズームが1回ごとに飛んでカクカクしていた。ホイールでは目標の拡大率だけを動かし、実際の拡大率は毎フレーム、目標との差(対数)に比例した速さで寄せるようにした(`src/ui/smoothZoom.ts`、時定数 70ms)。1回のホイールで最後に動く量は変えていない。主ビュー・3面図のどれにも効かせる。
- タッチパッドのピンチ(ctrlKey 付きのホイール)は、細かいイベントが続けて来て元からなめらかなので、寄せずにその場で変える。寄せると指より遅れ、指を止めたあとも動き続けるため。
- 寄せている途中にほかの操作が視点を変えたら、寄せるのをやめる。最後に書いた値と違うか、拡大率を持つオブジェクトが差し替わったかで見分ける(リセットや読み込みが同じ値を書いても気づけるように)。
- 寄せている途中にキーフレームやお気に入りへ今の視点を取り込むと、途中の値が入る。着くまで 0.3 秒ほどで、ボタンを押すまでの間に着くので、手当てしていない。

## 2026-11-13 視点の回転とズームでも揺らす

- 前は視点の平行移動(と「揺らす」)だけを慣性力にしていた。回転とズームでも揺れてほしいという要望で広げた。
- 方式は2案から「物理どおり」を選んだ(ユーザの選択)。カメラから見た各レイヤーの代表点(ウェイトの重心を、ポップ量だけ手前へ出した所)の加速度を、画像の向きへ戻して慣性力にする。平行移動と同じ考え方なので、どの向きから見ても揺れの向きが見た目と合う。もう1案の「回転の角度とズームの変化に係数を掛けて力にする」は、どのレイヤーも同じように揺れて分かりやすいが、斜めから見ると揺れの向きが見た目とずれるので選ばなかった。
  - そのため、画像の中央にある低いふくらみは回転ではあまり揺れない。回し続けている間は、注視点から離れたレイヤーが外へ少し傾いたままになる(遠心力)。どちらも方式どおりとした。
- ズームは、カメラが拡大率の対数に比例して近づく・離れる動きとして扱う(`ZOOM_DEPTH`)。本当のカメラの距離は画面の縦横比や画角で変わり、記録の再生や書き出しで揺れが変わってしまうため。対数なので、どの拡大率でもホイール1段の揺れは同じ。画角を変えても揺らさない。
- 記録の再生・キーフレーム・書き出しでも、記録した視点の向きとズームで揺らす(ユーザの選択)。記録中に見た揺れと書き出しを一致させるため。回転を含む保存済みの記録は、前と揺れ方が変わる。
- 強さの設定やオンオフは足していない(平行移動と同じくいつも効かせる)。3面図の自由角度の視点では揺らさない。
- ならした速度はレイヤーごとに持つ。視点が動いている途中で揺れを有効にしたレイヤーは、今の速さから測り始める(0 から急に動き出したとみなすと弾むため)。

## 2026-11-13 キーフレームの枠と経路を3Dビューに重ねる

- 要望は「登録したフレームを薄く表示し、動きの経路を矢印で、順番が見えるように」。キーフレームは視点の登録なので、4案(枠と経路を重ねる・ゴーストを半透明で重ねる・一覧にサムネイル・3面図に経路)から「枠と経路を重ねる」を選んだ(ユーザの選択)。線だけで軽く、スマホでも使えるため。
- 矢印には次のフレームまでの秒数を書く(ユーザの要望)。
- 枠の形では、ズームを変えたキーが大きさの違う枠として並ぶだけで前後の動きに見えない、という指摘があり、一度「各キーで画面に映る絵を半透明で重ねる(ゴースト)」に作り直した。触ってみて意図と全く違い、枠の方がまし、ということで枠に戻した(ユーザの判断)。ゴーストは蒸し返さない。動きの見え方を見せる方法は、まだ決まっていない(小さなプレビュー窓・時間のグラフの案は残っている)。
- 経路は記録を作るのと同じ曲線(`keyCurve`)から取る。描いた経路と再生の動きをずらさないため。枠と経路は画像の面(持ち上げる前の平面)の上で求め、揺れやピストンでは動かさない。
- 枠は今の主ビューの縦横比で映る範囲。書き出しの縦横比ではない(ウィンドウの大きさでも変わる)。
- 出すのはキーフレームの部品が見えているときだけ(右パネル・スマホのシートでアニメーションを開いているとき。シートを畳んでいるときは出さない)。記録中・再生中・書き出し中は出さない。
- 描くのは描画の直後(`frame`)だけ。ほかの知らせの時点ではカメラの行列が今の視点と合っていないことがあり、古い位置で描いて残るため。
- 番号は押して離すとその視点へ移る。番号の上で始めたドラッグは3Dビューに渡さない(ブラシなどで点を打たないため)。ホイールだけ3Dビューへ回す。
- 線の縁取りは CSS の filter を使わず、暗い線を下に敷く。視点を動かす間は毎フレーム描き直すため。
- 一覧は、フレームの行(番号・通り方・上書き・削除)と、その間の秒数の行を交互に並べる。秒数はフレームの間の値で、通り方はそのフレームの瞬間の値(止まらず通り抜けるか、勢いよく着いて止まるか)だから(ユーザの要望)。最後のフレームの後には、最初へ戻るまでの秒数と薄い「1」を出す。秒数の欄は使えるので薄くしない。

## 2026-11-14 クラウドで落ちる E2E を直し、手元だけで流すテストを分ける

- 一時停止中に変化が無ければ描かず CPU を減らす案(1ページ放置で約 3.6 コア → 0.4 コアになった)は、アプリの動きを変えるので、今回は入れていない。

## 2026-11-14 キーフレームをドラッグで並べ替える

- キーフレームの順番をドラッグ&ドロップで入れ替えたい(ユーザの要望)。行の左端に点のつまみを足し、そこをドラッグする。行全体をつかむ形にしなかったのは、行の中に番号・通り方・上書き・削除のボタンがあり、押し間違えるため。
- 並べ替えで動くのは視点と通り方で、フレームの間の秒数は場所に残す(ユーザの選択)。一覧の秒数の行はドラッグしないので、見た目どおりにするため。
- HTML のドラッグ&ドロップはスマホ(Android)の指で動かないので、pointer イベントで受け、つまみだけを `touch-action: none` にした(シートや一覧のスクロールは、つまみ以外で今までどおり)。キーボードでは、つまみを選んで ↑↓ で1つずつ動かす。
- キーフレームの下書きの編集は元から元に戻せない(作るときにアンドゥに積む)ので、並べ替えも同じにした。再生中に並べ替えても再生は止めない(秒数・通り方を変えたときと同じ。次の ▶ で作り直す)。

## 2026-11-14 未保存の判定・タブの上限・レイヤー一覧・ツールのメニューの手直し

- 視点(回転・平行移動・ズーム・正面に戻す・移動ツール・3面図の自由角度)を動かしただけでは「未保存」にしないことにした(ユーザーの要望)。見るだけのときも揺らすために視点や画像を動かすので、閉じるたびに確認が出て煩わしかったため。前は視点が保存される項目なので「未保存」にして自動保存していた。
  - 視点はこれまでどおりファイルに入る。編集して保存・自動保存すると、そのときの視点で保存される。視点だけ動かして閉じると、その視点は残らない。
  - 自動で揺らすの入・切、画角、キーフレーム・お気に入りなどは、作品の設定なので今までどおり「未保存」にする。
- タブが上限(5枚)のときは、開く・最近開いたファイル・サンプルを開く(メニュー・左のツールバー・スマホの「…」とシートの「ファイル」・スマホのタブの一覧の「開く…」)を使えなくし、理由をメニューの先頭とタブの一覧に出す(ユーザーの要望)。前は押せて、ファイルを選んだ後で断っていた。ショートカット(Ctrl+O)で押したときは、選ぶ画面を出さずに知らせる。ドロップや起動時の復元は、前もって止められないので、今までどおり開くときに断る。
  - 視点を動かしただけのサンプルのタブは「未保存」にならないので、次に開いたファイルで置き換わる(前は回すと未保存になり、別のタブで開いていた)。変更していないサンプルのタブは置き換えて開けるので、上限でも使える。
- レイヤー一覧の行の左にあった色の点(重ね表示の色)は、サムネイルをレイヤーの色で描くようになったので外し、名前の欄を広げた(ユーザーの要望)。塗っていないレイヤーのサムネイルは色が薄くて見分けにくいので、サムネイルの下の縁にレイヤーの色の線を引いた。
- 上のメニューに「ツール」を足した(ユーザーの要望)。中身は左のツールバーと同じ表(`src/ui/tools.ts`)から作り、選んでいるツールに ✓ を付ける。置き場所は、ツールバーでツールが操作より上にあるのに合わせ、「編集」と「表示」の間にした。スマホは下のバーでツールを選ぶので、「…」のメニューには足していない。

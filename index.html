    レイヤー

      レイヤー:

      塗った所を持ち上げる高さ(0〜1500px)。スライダーの右端は設定(右上の歯車)の「スライダーの最大値」で、既定は 500px です。最大値を 1000px より大きくすると、スライダーは前半で 0〜500px を細かく、後半を粗く動かします。複数のレイヤーを選んでいるときは、一番高いレイヤーの値を出し、ほかのレイヤーは同じ比率で伸び縮みします(0px のレイヤーは 0px のまま)。

      画像を開くと、選んだ重ね方の説明がここに出ます。

      揺れ

      画像を開くと、選んだプリセットの説明がここに出ます。

      詳細設定

      揺らし方・硬さ・質量・おさまりはプリセットの中身で、変えるとプリセットは「カスタム」になります。重さはプリセットに含みません。

      お気に入り

      今の揺れと動きの組み合わせ(全レイヤーのポップ量・重ね方・揺れ、自動揺らし、操作の記録とキーフレーム、視点)をお気に入りに追加します。画像とウェイトは残さないので、ファイルはほとんど大きくなりません。「適用」でその組み合わせに戻ります(視点のほかは元に戻せます)。● は今の状態と同じものです。名前はその場で書き換えられます。プロジェクトに保存されます。

      いい動きを見つけたら「☆ 追加」。

        自動揺らし

        操作の記録

        つかむ・揺らす・移動・視点の操作を覚えます(最長 60 秒)。ループ再生中も、回転・平行移動・ズームで視点を動かせます(画像のほうが記録どおりに動きます)。動かした視点は、キーフレームの下の「カメラを戻す」で再生を始めた視点へ戻せます。塗る・つかむ・揺らすなどで画面を触ると止まります。記録はプロジェクトに保存され、書き出しの「記録した操作をループ再生」にも使えます。再生中と記録中は、3Dビューの下に進み具合のバーが出ます。再生中はバーを押す・ドラッグするとその位置へ移り(移った先の揺れは落ち着いた状態から始まります)、一時停止(Shift+L)もできます。キーフレームの動きなら、各フレームの番号を押すとその時刻へ移ります(キーボードでは PageUp・PageDown)。

        キーフレーム

        重ねて表示

        視点(回転・ズーム・画像の位置)を順に通り、最後から最初へ戻ってくり返す動きを作ります。画像の位置が動くと揺れます。フレームの間の秒数は、次のフレームまでの時間です(最後の後の ↩ は、最初へ戻るまでの時間)。「通り方」は、そのフレームを、なめらか(止まらず通り抜ける)か、弾む(勢いよく着いて止まり、揺れる)かを選びます。行の左端の点をドラッグすると順番を入れ替えられます(間の秒数は場所に残ります)。点を選んで ↑↓ キーでも動かせます。作った動きは今の記録と入れ替わります(元に戻せます)。「経路」をオンにすると、1番のフレームの視点をカメラとして止めたまま画像のほうが動くとみなし、各フレームで画像が来る所を枠で、順番を番号で、画像の中心の動きを矢印と秒数で3Dビューに重ねます。1番の視点から見ると、そのカメラで映る並びになります。視点を動かすと横や上からも見られます。番号の形は通り方で、丸がなめらか、ひし形が弾むです。番号を押すとその視点へ移ります。「ゴースト」をオンにすると、同じ所に画像を半透明で重ねます。どちらも記録中・再生中は消えます。「シークバー」をオンにすると、フレームが2つ以上(1周 0.5 秒以上)ある間は、このタブを開いていれば止まっていても3Dビューの下に再生のバーが出ます(手で記録した操作があるときは出ません)。バーを押すと、その時刻で一時停止した状態から再生が始まり(一覧が今の記録と違えば作り直します)、▶ で続きから流れます。

          ウェイト表示

          塗った所を色で重ねます。「選択中」は選んでいるレイヤーだけ、「全レイヤー」は表示中のレイヤー全部を、一覧の色の印と同じ色で重ねます(選んだレイヤーは濃く、ほかは薄く)。W キーと左のツールバーの「ウェイト」は、押すたびに OFF → 選択中 → 全レイヤーと切り替えます。

          画像を薄くして、塗りを見やすくします(書き出しには影響しません)。

          ポップと揺れを一時的に消して、平らに表示します(書き出しには影響しません)。

          すべてのレイヤーの揺れを一時的に止めます(保存・書き出しには影響しません)。

          正面・右・下から見た図と、角度を変えられる図を横に並べます。

            まだありません。画像やプロジェクトを開くか保存すると、ここに並びます。

              一覧はこのブラウザの中だけに保存されます。Chrome / Edge ではファイルの場所を覚え、開き直すときに読む許可を求めます。ほかのブラウザでは中身のコピー(1件 50MB まで)を覚えます。

              設定

              ブラシ

              ペンの筆圧を、ブラシ・消しゴム・ぼかしの強さかサイズに効かせます。マウスや指で塗るときは変わりません。

              ウェイトの重ね表示

              ブラシ・消しゴム・ぼかし・膨らみに切り替えたときや「全体をぼかす」を開いたときに、ウェイトの重ね表示を自動でONにします。手でONにした表示は、この設定では変わりません。

              自動でONにした重ね表示を、ほかのツールに移ったときや「全体をぼかす」を閉じたときにOFFにします。手でONにした表示や、塗っている間に手で切り替えた表示はそのまま残します。

              ポップ量

              px

              ポップ量と「膨らませる」の高さのスライダーの右端です(100〜1500px)。小さくするとスライダーで細かく動かせます。数値の欄には、この値を超えて 1500px まで打てます。

              UIを隠す

              「UIを隠す」(Tab)を使ったときに、ブラウザのタブやアドレスバーも隠して画面全体に出します。Esc で全画面をやめると、UIも戻ります。

              左のツールバーに出すボタン

              チェックを外したボタンは左のツールバーから隠します。隠してもショートカットとメニューからは使えます(隠したツールを選んでいる間は、ツールバーに選んだ印が出ません)。

              操作方法

              1本指下で選んだツールで操作 画像の外なぞると回転、ダブルタップで視点を戻す 2本指動かすと平行移動、つまむとズーム 2本指タップ元に戻す 3本指タップやり直す 微調整右上のボタンでオンにすると、動きが 1/5 になる レイヤーを複数選ぶ一覧で長押しして、タップで足す・外す 膨らみ・塗る・消すシートの「レイヤー」→「塗って直す」 操作の記録シートの「アニメ」→「操作の記録」 設定右上の「…」→「設定…」
              1. 画像をウィンドウへドロップする
              2. ブラシで動かしたい所を塗る
              3. 視点を回して、ポップ量を調整する
              4. 「つかむ」で揺らし、プリセットを選ぶ
              5. ファイル → 書き出しで保存する

              キーボード

              PukuPop

              画像を3D空間に置き、塗った所を平面から持ち上げて、ぷるぷる揺らせる Web アプリです。
              ブラウザだけで動き、画像やプロジェクトをサーバーへ送りません。
